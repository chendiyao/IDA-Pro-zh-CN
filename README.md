# IDA-Pro-zh-CN

IDA Pro 9.x 简体中文汉化插件（基于 IDAPython + PySide6，无需修改二进制文件或签名）。

- **作者**：CHENDIYAO
- **仓库**：https://github.com/chendiyao/IDA-Pro-zh-CN
- **声明**：允许自由使用与转发，**转发或二次分发请务必保留作者署名（CHENDIYAO）及本仓库链接**。

---

## 简介

以往的 IDA 汉化大多采用直接修改 `ida.hlp`、替换动态库字符串或打包专属安装包的做法。这类方式在升级小版本时容易失效，且在 macOS 下破坏二进制签名会导致启动报错或崩溃。

本插件完全运行在 IDAPython 层，通过 `ida_kernwin` 与 `PySide6` 在运行时挂载界面翻译，不触碰任何 IDA 原生文件，删掉插件即可随时恢复英文原版。

---

## 覆盖范围

词库（`ida_zh_cn_dict.json`）结合 IDA 9.x 逆向工程常见场景手工校对，共包含 **5,200+** 条界面词条：

- **顶部菜单栏**：`文件`、`编辑`、`跳转`、`搜索`、`视图`、`调试器`、`选项`、`窗口`、`帮助` 及各级子菜单（含 `打开子视图`、`流程图`、`工具栏` 等动态菜单）。
- **工具栏与右键菜单**：主窗口全部 25 个工具栏名称与按钮提示；反汇编视图、伪代码视图、函数列表、结构体/本地类型、十六进制视图、导航栏等右键上下文菜单。
- **核心对话框（100+）**：
  - 启动欢迎页（快速开始、拖放提示、最近文件列表）
  - 加载新文件（处理器架构选择、加载段选项、内核分析参数 1~3、处理器专用分析选项）
  - 常规选项（反汇编、空行与前缀、显示格式、伪代码/Hex-Rays、调试器、Lumina、Teams 等全部分页）
  - 颜色与主题、字体设置、快捷键配置
  - 查找/二进制搜索/文本搜索、跳转到地址、修补字节、计算器、重命名、添加断点、修改函数签名、运行脚本等
  - 选择调试器、进程附加、异常定义、调试器连接配置
  - 关闭/保存数据库选项（不打包、存储、压缩、垃圾回收等）
- **停靠面板与状态栏**：
  - 停靠标签页标题与单窗口标题栏（`反汇编视图-A`、`伪代码-A`、`输出窗口`、`函数`、`字符串`、`导入表`、`导出表` 等，自动保留同步视图后缀）
  - 彩色导航栏图例（`库函数`、`普通函数`、`指令`、`数据`、`未分析字节`、`外部符号`、`Lumina 函数`）及比例尺提示
  - 底部状态栏（`自动分析: 空闲`、`磁盘可用:`、`第 X / Y 行` 等）

### 默认保留英文的部分

以下内容涉及符号解析、脚本接口或内部标识，强行翻译会影响正常逆向工作，因此插件特意保留原文：

1. **表格数据列头**：如函数列表的 `Name / Address / Size`、段表的 `Perm / Class` 等（避免影响排序与脚本按列名索引）。
2. **快捷键列表内部动作名**：`Shortcuts` 弹窗中的 `Action` 内部 ID（如 `Abort`、`AddWatch`），方便对照 `ida_kernwin.process_ui_action()`。
3. **动态反汇编与日志输出**：反汇编助记符、寄存器、伪代码变量以及 Output 窗口的 IDAPython 控制台输出。
4. **原生系统级文件框**：macOS / Windows 系统托管的打开/保存文件对话框（跟随操作系统语言）。

## 安装方法

确保你的 IDA Pro（9.0 ~ 9.5）已启用 IDAPython 和 PySide6，将仓库中的两个文件放入用户插件目录：

- `ida_zh_cn.py`
- `ida_zh_cn_dict.json`

### 插件目录路径

- **macOS / Linux**：`~/.idapro/plugins/`
- **Windows**：`%APPDATA%\Hex-Rays\IDA Pro\plugins\`

**macOS 终端一键安装：**

```bash
mkdir -p ~/.idapro/plugins
cp ida_zh_cn.py ida_zh_cn_dict.json ~/.idapro/plugins/
```

重启 IDA Pro 即可生效。可以在运行过程中按 `Ctrl+Shift+L` 随时刷新汉化状态。

## 实现原理简述

插件通过三层机制协同工作：

1. **Action 元数据同步**：使用 `ida_kernwin.get_registered_actions()` 与 `update_action_label()` 更新内置动作的标签与提示（跳过顶层菜单容器与纯图标工具栏项，避免覆盖按钮图标或触发 macOS 原生菜单栏重建冲突）。
2. **Qt 事件过滤器（`QObject.eventFilter`）**：挂载在 `QApplication` 上，仅监听 `QMenu`、`QDialog`、`QTabBar` 等顶层容器的 `Show` / `WindowTitleChange` 事件，在弹窗和右键菜单弹出瞬间完成文本替换。
3. **表单控件递归匹配**：兼容 IDA `ask_form` 生成的快捷键标记（`&` / `_`）、冒号后缀以及动态正则模板（如加载文件路径、导航栏缩放比例、状态栏行号等），并将原始英文保存在控件自定义属性中，防止重复翻译。

需要补充或调整译文时，直接编辑 `ida_zh_cn_dict.json` 即可。
